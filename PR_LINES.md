# Pull request guidance

Keep pull requests concise and scoped to the requested change.

## Description

- State the visible change and why it is needed.
- Mention any change to image fitting, caption positioning, or metadata.
- Summarise validation and any remaining limitations.

## Review checklist

- [ ] Preserve the full photograph without cropping unless requested otherwise.
- [ ] Keep captions and metadata consistent.
- [ ] Check narrow mobile and desktop layouts when layout changes.
- [ ] Use plain HTML/CSS; add browser JavaScript only when needed.
- [ ] Avoid dependencies and build tooling without a concrete reason.
- [ ] Describe deployment separately from a successful GitHub commit.
