# paulwalsh.net

A minimal photography homepage built with plain HTML and CSS.

## Files

- `index.html` — responsive homepage and pale grey top-left caption: Lake Pukaki 2016.
- `pw-bg.png` — original photograph/artwork.
- `TODO.md` — actionable tasks.
- `ROADMAP.md` — possible future improvements.
- `PR_LINES.md` — concise pull request guidance.

## Run locally

Open `index.html` directly in a browser. No installation, build step, framework, or JavaScript is required.

## Hosting

Upload `index.html` and `pw-bg.png` to the same directory on the web host. The image scales to fit the viewport without cropping. The repository does not currently configure automated deployment.

## Design

Keep the image central, the caption subtle, and the implementation mobile first. Use native HTML, CSS, and browser JavaScript only when needed.
