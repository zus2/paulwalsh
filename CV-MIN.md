- **[Pybricks Train Controller](https://github.com/zus2/pybricks-asynchronous-train-controller)** — Asynchronous Python controller for LEGO trains, with realistic acceleration and braking, saved crawl-speed calibration, and support for a second hub.
- **[XVA ≈ A Guessing Game](https://xva.com)** — Installable, offline-capable mental-estimation game with timed and practice modes, results visualisation, local personal bests, and completed-round analytics using Cloudflare Pages/D1.
- **[WordPress Reseller Store](https://github.com/zus2/wp-reseller-store)** — Work with GoDaddy’s WordPress reseller storefront plugin, covering domain search, product catalogues, localised pricing, and shopping-cart integration.
